# GamersLife — Minecraft Forge 1.20.1

## Features
- 4 drinks: Energy Drink, Gamer Soda, Lucky Fizz, Gamer Shake.
- Each drink can be right-clicked 3 times.
- Every use grants:
  - Strength I
  - Jump Boost I
  - Luck I
  - Regeneration I
- Effects last 5 minutes (6000 ticks).
- After the third use, the drink is consumed.
- Craftable Gaming PC block.
- Right-click the PC to open a desktop-style GUI.

## Build
Requirements:
- Java 17
- Minecraft Forge 1.20.1 / Forge 47.x

On Windows:
    gradlew.bat build

On Linux/macOS:
    ./gradlew build

The finished JAR will be in:
    build/libs/gamerslife-1.0.0.jar

## Install
Put the JAR into your Minecraft 1.20.1 Forge `mods` folder.
